# 📊 HR Talent Retention & Employee Exit Analytics Dashboard

## 📌 Project Overview

The **HR Talent Retention & Employee Exit Analytics Dashboard** is an interactive Business Intelligence project developed using **Microsoft Power BI**.

The project analyzes employee attrition using an HR dataset containing **1,470 employee records** and provides interactive insights into employee turnover patterns across department, job role, tenure, overtime, job satisfaction, work-life balance, gender, and income.

---

## 🎯 Objectives

- Analyze employee attrition patterns
- Identify workforce segments with higher attrition
- Monitor key HR performance indicators
- Analyze factors associated with employee turnover
- Build an interactive and easy-to-understand Power BI dashboard
- Provide data-driven insights for HR analysis

---

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Power BI Data Model
- Microsoft Excel for validation

---

## 📂 Dataset

The project uses an **HR Employee Attrition dataset** containing:

- **1,470 employee records**
- **35 original columns**
- Employee demographic information
- Department and job role
- Monthly income
- Overtime
- Job satisfaction
- Work-life balance
- Years at company
- Attrition status
